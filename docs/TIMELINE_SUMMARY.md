```
Decision 1: HTML vs Framework?
├── Considered: Next.js, React, Vue
└── ✓ Chose: Static HTML for simplicity & speed

Decision 2: Dark vs Light Theme?
├── Considered: Light-mode first
└── ✓ Chose: Dark navy (#0A0F1E) for premium feel

Decision 3: Content Format?
├── Considered: Headless CMS, MDX, Database-driven
└── ✓ Chose: Static HTML + documentation

Decision 4: Analytics Approach?
├── Considered: Event-driven later
└── ✓ Chose: Measurement-first (plan before building)

Decision 5: Backend Services?
├── Considered: Custom backend, Firebase
└── ✓ Chose: Supabase + Resend (simple, scalable)

Decision 6: Deployment?
├── Considered: GitHub Pages, AWS, custom VPS
└── ✓ Chose: Vercel for performance & ease

Decision 7: Development Method?
├── Considered: Traditional hand-coding
└── ✓ Chose: AI-powered (Claude Code) for speed
```
